# CerenityInnovation-LandingPage

Cerenity Innovation's website — served via GitHub Pages at **cerenityinnovation.com** (see `CNAME`).

## Pages
- `index.html` — home (AI Agents)
- `enterprise.html` — Enterprise
- `app.html` — App
- `news.html` — News & press

## Notes
- Pages are rendered by `support.js`, a small runtime that loads React / ReactDOM / Babel
  from the unpkg CDN at page load, so an internet connection is required to view the site.
- `image-slot.js` provides drop-in image placeholders used on some pages.
- Static image assets live in `assets/`.
